# SmartFlow

## What is SmartFlow

**SmartFlow** is a free tool that speeds up your work by giving **your AI** assistant better guides, to the point where it acts like a **coworker**.

## How to install

Run this in your AI editor (it must have access to the editor's config folder):

    Please install SmartFlow for me, thanks:
    https://raw.githubusercontent.com/GunSweat/SmartFlow/refs/heads/main/InstallGuid.json

## Folder structure

    SmartFlow/
    ├── Modules/      Optional add-ons (toggle each one on/off)
    ├── Scripts/      Reusable scripts
    ├── Workspace/    Code you are working on
    └── Playground/   Executing and testing

## Commands

All commands use your prefix (default `$`), e.g. `$Enable`.

| Command | What it does |
|---|---|
| Enable / Disable | Turn SmartFlow on or off |
| Help | Show all commands |
| Status | Show version, prefix, and module states |
| Modules | Review and toggle modules |
| Prefix | Change your command prefix |
| Uninstall | Remove SmartFlow |
